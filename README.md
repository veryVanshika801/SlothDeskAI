## SlothDesk AI

### Work smarter. Move slower. Get there.

**SlothDesk AI** is an AI-powered productivity companion designed to turn overwhelming tasks into manageable steps. From organizing messy thoughts to creating realistic daily plans, it helps you stay productive without the pressure.

🌐 **Live Demo:** https://slothdeskai.ai.studio 

💻 **Repository:** https://github.com/veryVanshika801/SlothDeskAI

---

## ✨ Features

- **📝 Lazy Task Organizer** — Transform unstructured thoughts and brain dumps into actionable tasks.
- **🌿 Low-Energy Mode** — Find manageable priorities based on your energy and available time.
- **🪜 Make It Smaller** — Break overwhelming tasks into simple, achievable steps.
- **📋 Note-to-Action Converter** — Turn notes into summaries, decisions, and action items.
- **📅 Slow Planner** — Create flexible daily plans that respect your time and priorities.
- **🌳 Sloth Garden** — Celebrate progress and grow your virtual garden as you complete tasks.
- **📊 Productivity Dashboard** — Keep track of tasks, progress, and recent activity.
- **🦥 Calm User Experience** — Enjoy a sloth-inspired interface designed around mindful productivity.

## Our Mission

Productivity shouldn't mean doing everything at once.

SlothDesk AI encourages a more sustainable approach to getting things done by simplifying complex tasks, reducing mental overload, and celebrating small wins.

## Getting Started

### Prerequisites

- Node.js and npm
- Git
- An AI provider API key if you want to use live AI generation

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/veryVanshika801/SlothDeskAI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SlothDeskAI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables for your selected AI provider using the project's environment configuration.

   Never commit API keys or other secrets to GitHub.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal.

### Production Build

Build the frontend using:

```bash
npm run build
```

Use the deployment configuration and required environment variables documented in the project to deploy the application on Vercel.
